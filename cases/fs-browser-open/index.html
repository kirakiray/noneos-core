Case 01 / 03
Local filesystem

写入本地虚拟文件， 再用浏览器 GET 打开

把一段 HTML 写进 OPFS 虚拟文件系统，然后通过 /$cases-demo/hello.html 这条普通 URL 打开它。整个过程没有后端文件服务器，浏览器就是你的运行环境。

nos/fs OPFS Service Worker 路由 实时预览
演示步骤 1 / 4
    代码记录 保留每一步
    Step 01

    准备一个 OPFS 存储空间

    init("cases-demo") 会在浏览器的 Origin Private File System 里创建（或复用）一个根目录。这里的数据只属于当前浏览器来源。

    这一步同时创建一个空的 hello.html 文件句柄， 下一步再写入内容。
    重新运行本步 完成后点击「下一步」
    Step 02

    把 HTML 写进虚拟文件

    拿到文件句柄后，直接用 file.write() 写入字符串。 写入的内容会持久化在 OPFS 中，刷新页面也还在。

    注意：这里写入的是应用自己的虚拟目录，不是用户磁盘上的任意文件。
    重新运行本步
    Step 03

    通过浏览器 GET 打开

    Service Worker 会把 /$cases-demo/hello.html 映射到刚才的 OPFS 文件。用普通 fetch() 或 iframe 就能访问，就像它是一张真实的网页。

    右侧会显示 HTTP 状态、响应文本和真实 iframe 预览。
    重新运行本步 在新窗口打开
    Step 04

    修改文件，URL 立即更新

    再次写入同名文件，不需要重新部署。下一次 GET 会读取到新内容；这就是可持久化、可热更新的浏览器文件系统。

    • 文件路径保持稳定
    • 内容可以随时覆盖
    • 刷新浏览器后数据仍然存在
    重新运行本步 在新窗口打开
